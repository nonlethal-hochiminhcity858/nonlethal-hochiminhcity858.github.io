Bubbles-Terminal - Keep Your Windows Shells Organized

Download Bubbles-Terminal

📋 About This App

Bubbles-Terminal sits on your desktop as a single window. It manages your existing command tools like PowerShell, Command Prompt, and Git Bash. It does not replace these programs. Instead, it acts as a container to help you organize multiple windows into one view. You see all your active shells in one place, which saves space on your taskbar.

💻 System Requirements

Your computer needs the following to run this software:

  • Windows 10 or Windows 11 operating system.
  • A 64-bit processor.
  • At least 4GB of RAM.
  • The latest version of .NET Desktop Runtime installed on your machine.

🚀 Installing the Software

Follow these steps to set up the application on your computer:

  1. Go to the official download page.
  2. Look for the section labeled "Assets" under the most recent release.
  3. Select the file that ends in .msi or .exe to start your download.
  4. Open the file once the download finishes.
  5. Follow the prompts on your screen to complete the installation.

⚙️ How to Use

Launch Bubbles-Terminal from your Start Menu after installation. Upon opening, the app detects your installed shells automatically. You can click the plus icon to add a new tab. Select the type of shell you want to launch, such as PowerShell or Git Bash. Every tab works exactly like the original program. You can move between tabs using your mouse or keyboard shortcuts.

🛠 Customization

You can change the look of your terminal window inside the settings menu. Adjust the font size to suit your eyes. Choose from several color themes to make your work area comfortable. These settings save automatically to your user profile folder.

❓ Frequently Asked Questions

Does this app replace my existing terminals? No. It just displays shells like PowerShell or CMD within a new frame.

Is this app safe? Yes. It performs the same tasks as your system shells and does not include hidden code.

Can I use this with WSL? Yes. If you have Windows Subsystem for Linux installed, the app detects it as a valid shell option.
